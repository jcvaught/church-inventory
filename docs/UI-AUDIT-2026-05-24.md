## Patterns across the audit

1. **Color-only status** is everywhere — StockBar, expiry dots, swap-status, overdue text — and almost never paired with a text label or `aria-label`. Single pattern fix would resolve ~15 findings.
2. **Emoji as icons** with no `aria-hidden`/`aria-label`. A primitive `<Icon emoji="📦" label="Inventory" />` wrapper would normalize this.
3. **Modal/toast feedback gap** — success states often close silently; destructive actions often skip confirm; drafts are never preserved. One reusable "destructive action" pattern + a uniform success-toast convention closes a dozen findings.
4. **Mobile cramming** — the same pattern (5-col grids, pill rows, action buttons) breaks at the same widths across multiple pages. A tablet breakpoint between mobile and desktop is missing in the design system.
5. **Insights a11y** — charts are entirely visual. A "View data table" disclosure is the cheapest universal fix.
